Quick Draw

Function Syntax DYL-QUICKDRAW (preset dialog) + 35 preset commands – see Commands
Source File Modules\Dynalisp\Apps\Draw\Dyl-QuickDraw.lsp
Requires AutoCAD for Windows (ActiveX / Visual LISP); the hatch patterns listed below on the support path; Dynalisp layer keys (Layer Keys) and preset engine (Remote\Dyl-Presets.lsp) and materials (Remote\Dyl-Materials.lsp), loaded at startup

Program Description

Thirty-five draw-and-fill commands for phase screens and section materials. Each command makes a closed outline with a standard AutoCAD drawing tool (polyline, rectangle, circle… see Draw With), puts it on the layer of the outline layer key of its material, and fills it with a hatch (associative or not, as set in the material) using the pattern, scale, angle and hatch layer key of the material. The hatch scale switches automatically between imperial and metric values.

The main command DYL-QUICKDRAW opens a preset editor: a preset is a name, a material and a Draw with method. Several presets can share one material: QD-BRICK (asks the method) and a PL-BRICK preset drawn with a polyline both use the Brick material, so editing the material changes both. Presets can be edited, created, and reset to their default values. The presets are saved to Modules\Dynalisp\Res\QuickDraw.csv, the materials to Materials.csv; the QD-* commands use the values saved there, so a default preset edited in the dialog changes its command too. Each custom preset gets a command too, Pst-QuickDrawCustom<Name> (e.g. Pst-QuickDrawCustomTest): it is listed in Dyl-Suite under DYL-QUICKDRAW, where aliases can be added to it, and it keeps working when the preset is renamed (its id is saved in the Id column).

Preset Dialog

  • Filter / Sort by – above the list (same in the Materials and Quick Shape windows): type a part of a group, name, alias, status or material (the pattern in the Materials window) and press Enter to list only the presets that have it (any case; empty: every preset), the number listed shown next to it. The selected preset stays listed; when it does not match, the first one that does is selected. Sort by lists them in file order, by group then name, by name or by status (custom, modified, then default), kept for the session.
  • Preset list – one column each, titled at the top: group, name, aliases (the short names that run the preset) and status (blank = default values, modified = edited default preset, custom = preset created by the user). Double-click a preset to draw it.
  • Parameters – name, group, Material (list of the materials, group - name, with a summary of the selected material below it) and the Draw with method. Each value is checked when the field is left (unique name, no empty field, existing material); an invalid value must be fixed before another preset can be selected. A material that was deleted stays in the list, marked (missing material), until another one is picked.
  • Edit materials... – opens the Materials dialog on the material of the preset. The material selected there when it is closed with OK is given to the preset, so a new material can be made and picked in one go. The Materials dialog saves Materials.csv on its own OK, even if the preset dialog is then cancelled.
  • New – adds a custom preset after the selected one, in the same group. Copy – adds a custom preset with the values of the selected one.
  • Delete – removes the selected custom preset and its aliases (default presets cannot be deleted, only reset).
  • Aliases of the preset command – the aliases of the selected preset (the short names that run it, e.g. QD-BRICK), as in Dyl-Suite: Add creates the alias typed, Rename gives the alias picked the name typed, Remove deletes the alias picked. The box starts with PL- for a preset drawn with a polyline, QD- otherwise. An alias cannot be the name of a command, another alias or an AutoCAD command. A new custom preset gets its command (from its name) with its first alias. The aliases are saved to Resources\Aliases.csv with Draw or Save, and Cancel discards them.
  • Reset Selected – (bottom left) restores the default values of the selected default preset. Reset All – restores the default values of every default preset; custom presets are kept (renamed if a restored name is already used).
  • Draw saves the presets and draws the selected one, Save saves without drawing, Cancel discards every change made in the dialog.
  • Open Docs – opens the docs page of the tool (this page for Quick Draw, the Materials page in the Materials window); the dialog stays open.

The dialog reopens on the last preset used during the session.

Materials

Every parameter of a material, and the list of the default materials, is described on the Materials page.

A material is the hatch of an outline, shared by every preset that uses it, of Quick Draw and of Quick Shape. The Materials dialog has the same list and buttons as the preset dialog (New, Copy, Delete, Reset Selected, Reset All), without aliases: OK saves the materials and gives the selected one to the preset, Cancel discards the changes. Each default preset uses the default material of the same name (QD-BRICK → Brick).

  • Group – picked from a list, by the kind of drawing the material is used in: Floor, Ceiling, Roof, Finish, Structural, Site (plans, by their type), Elevation, Section, Detail, Annotation, Phase, Area, Generic. A group typed in Materials.csv that is not in this list stays selectable (the case of a listed group is corrected, e.g. section → Section).
  • Parameters – name and group, then three groups. The basic settings are always used; every other setting has a checkbox and its value stays greyed out until it is checked (unchecked: the layer of the layer key, or the AutoCAD default, is kept):
    • Hatch settings – pattern, imperial and metric scales, angle and hatch layer key (basic); then Color, Background color, Existing phase background (used in place of the background color while auto-phase is on and the active phase is E, existing to remain; PH-AUTO, with the DynALisp reactors on), Lineweight and Transparency (0-90). A color is an AutoCAD color number (1-255) or a true color r,g,b; its ... button opens the AutoCAD color dialog. Then how the hatch is scaled and made: Annotative hatch; Follow the drawing scale with the drawing scale its scales were set for (see Drawing Scale); Associative hatch (checked by default); Hatch behind its border (draw order). Scales must be > 0 and the angle numeric. For SOLID, the scales, the angle, the background colors, the lineweight, annotative, the drawing scale and the Linear hatch scale and origin are greyed out and not used.
    • Border settings – outline layer key (basic); then Color, Linetype (loaded from acad.lin or acadiso.lin when the drawing does not have it), Linetype scale, Lineweight and Transparency (0-90), given to the outlines; No border: the closed outlines are erased once hatched (the hatch is then not associative, the other border settings, Associative and behind its border are greyed out; the objects selected with Select closed objects are kept).
    • Material behaviors – how Quick Draw draws the material: Draw with, its input method (see Draw With; Ask when drawn by default), the Width and Line on the of the Linear method (empty width: the last one used; several widths divided by commas: asked among them when drawn) , Hatch scale = width x and Hatch origin on the line of the Linear method (see Linear) and the Sides of the Polygon method (empty: asked by POLYGON) and the Gap override (Shrinkwrap) of the Shrinkwrap method (off: from 0 with the gap step of Dyl-Settings; on: the Imperial or Metric gap, asked when empty; see Shrinkwrap). Each one is greyed out unless its method, or Ask when drawn, is picked: the method picked when drawn (or the one of a preset) uses them too.
  • Pattern – picked from a list of every pattern defined in the .pat files of the support path (acad.pat, acadiso.pat and custom pattern files). A pattern used by a material but not found in any file stays in the list, marked (not found on the support path).
  • Outline / Hatch layer key – picked from the Dynalisp layer keys, shown with their layer. A key used by a material but not defined stays in the list, marked (not defined): it draws on a layer of the same name. Edit layer keys... opens the Layer Keys dialog to create or edit keys; it saves LayerKeys.csv on its own OK.
  • Delete – removes a custom material. The presets that use it stay, marked (missing material): drawing them shows an alert until another material is picked.

Drawing Scale

A hatch that is not annotative keeps the scale of its material in every drawing. With Follow the drawing scale checked (in the Hatch scale box, greyed out while Annotative hatch is checked), its scale follows the drawing scale: the annotation scale of the drawing (CANNOSCALE, set by Dyl-SwitchDrawingScale).

Scales set for a drawing scale of 1: is the drawing scale the imperial and metric scales of the material were set for: 10 when they look right at 1:10. When the hatch is drawn, its scale is multiplied by the drawing scale divided by that number: set for 1:10 and drawn at 1:50, the scale is multiplied by 5; drawn at 1:5, by 0.5. The line under it gives the factor in the current drawing (This drawing is at 1:50: hatch scale x5.). A new material is set for 1:1.

The hatch is not updated when the drawing scale changes afterwards: it keeps the scale it was drawn with. The preset summary shows follows the drawing scale (set for 1:10) for such a material.

Draw With

A material draws with the Draw with method of its behaviors (Method column of Materials.csv). The Draw with list of a preset (Method column of QuickDraw.csv) keeps Method of the material (empty, the default of every default preset) or picks another method for that preset only. With no method in the preset nor in the material, the method is asked on the command line each time the preset is drawn: Draw with [Polyline/Rectangle/Circle/pOlygon/Ellipse/sHrinkwrap/pIck/Select/Linear] <Polyline>:. Enter keeps the method given last time (saved for the next sessions).

Linear

The Linear (band along a line) method draws a band of a given width from a line, like a wall, a strip of insulation or a curb, and turns its hatch to follow the line. Its material gives (Material behaviors) the default Width (drawing units; empty: the last width used, asked the first time; several widths divided by commas, 100,150,200: asked each time among them, Width [100/150/200] <100>:, the last width used by default) and where the line is in the band, Line on the: Ask when drawn (asked before the start point, the last one given by default), Center (on the line), Left border or Right border (looking from the start point, the band is then on the right or on the left of the line).

  • Start point or [Width/Justification] – pick the start of the line, or change the width or the justification for this band only (the material keeps its own; the width typed becomes the last width used).
  • Next point or [Undo] – pick the next points: the line and the borders of the band are shown while they are picked. Undo removes the last point, Enter ends the line.
  • Each segment becomes a closed outline, mitered with the next one at the corners, with its own hatch: its angle is the angle of the material plus the angle of the segment, so the pattern follows the line (a straight band is one outline and one hatch).
  • Hatch scale = width x (Material behaviors, checked) – the hatch scale is the width of the band times the factor typed (1: the width), in place of the scales of the material and of the drawing scale: a 100 wide band with a factor of 0.01 is hatched at the scale 1, a 200 wide one at 2, so the pattern fits the band whatever its width.
  • Hatch origin on the line (Material behaviors, checked) – the pattern of each segment starts at the start of the segment on the line, moved across the line by the offset typed (0: on the line; positive: into the band, to the left of the line for Center), so the pattern lines up with the line (e.g. the edge of an insulation pattern on the border of the band).

How It Works

  1. The hatch scale is picked from the drawing units: MEASUREMENT = 1 (metric) uses the metric scale, otherwise the imperial scale.
  2. The layer of the outline layer key is made current (created first with the key properties when the drawing does not have it), then the outlines are made with the Draw with method of the preset (asked first when the preset has none). The current layer is restored afterwards, also when the command is cancelled.
  3. Only closed polylines, circles, ellipses and splines are kept: an open outline that was drawn is erased (a selected one is skipped) and an alert is shown.
  4. The outlines are put on the layer of the outline layer key.
  5. One hatch is created on all the outlines with -HATCH (Select objects), associative or not and annotative or not as set in the material, using the pattern, scale and angle of the material (the scale multiplied by the drawing scale divided by the one it was set for, when the material follows it) (SOLID uses neither scale nor angle). Since the outlines are hatched together, an outline inside another one stays open (island). The hatch is then put on the layer of the hatch layer key (created if missing).
  6. Outlines and hatch are one undo step. If nothing was made, nothing is hatched.

Known Limitations

  • Patterns such as CONCRETE_C, WOOD_*, SITEWORK_* and GENERAL_* are not part of acad.pat: they must be available in a folder of the support path.
  • Patterns are only listed from the folders of the support path.
  • A layer that already exists in the drawing is used as is: the layer key properties only apply when the layer is created. Objects drawn on a layer that is off or frozen are not visible.
  • QuickDraw.csv and Materials.csv cannot be saved while they are open in Excel: an alert is shown and the changes are lost.

The rows marked ↳ are child commands of Dyl-QuickDraw: they are run by their alias, or picked from Dyl-QuickDraw when it lists them (their command is named Pst-*).

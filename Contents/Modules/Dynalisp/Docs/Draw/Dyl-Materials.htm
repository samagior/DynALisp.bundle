Requires AutoCAD for Windows (ActiveX / Visual LISP)

Program Description

DYL-MATERIALS opens the Materials window. A material is the hatch of an outline and the way it is drawn: pattern, scales and angle, layer keys of the hatch and of its border, optional colors, linetype, lineweight and transparency, and the behaviors that tell Quick Draw how to draw it (polyline, linear band, shrinkwrap...). The materials are shared by every preset of Quick Draw and Quick Shape, which open the same window with their Edit materials... button: changing a material changes every preset that uses it.

The Window

  • Filter / Sort by – the list shows the materials whose group, name, status or pattern contain the text typed (any case); Sort by orders them by File order, Group, Name or Status (kept for the session). The count of the materials listed is shown beside.
  • List – group, name and status of each material: empty for a default material as shipped, modified for a default material changed, custom for a material made with New or Copy. Click a material to show its parameters on the right.
  • New – adds a custom material after the selected one (see New material). Copy – adds a custom copy of the selected material. Delete – removes the selected custom material (default materials cannot be deleted, only reset). The presets that use a deleted material stay, marked (missing material), until another material is picked.
  • Reset Selected – gives the selected default material its shipped values back. Reset All – does it for every default material; custom materials are kept (renamed if a restored name is already used). The shipped values are the ones of Res\Materials.csv under Contents.
  • OK – saves the materials to your copy of Res\Materials.csv (under User, the shipped file is never changed) and, when the window was opened from a preset, gives it the selected material. Cancel – discards every change. Open Docs – opens this page; the window stays open.
  • A value that is not valid is shown at the bottom of the window, and the material cannot be left until it is corrected.

Parameters

The right side of the window shows the Name (unique), the Group and three boxes: Hatch settings, Border settings and Material behaviors. The basic settings are always used. Every other setting has a checkbox: its value stays greyed out until it is checked, and while it is unchecked the property is left as the layer of the layer key (ByLayer) or the AutoCAD default.

  • Name – the name shown in the lists and in the preset summary. Two materials cannot have the same name.
  • Group – the kind of drawing the material is used in, to sort and filter the list: Floor, Ceiling, Roof, Finish, Structural, Site (plans, by their type), Elevation, Section, Detail, Annotation, Phase, Area, Generic. A group typed in Materials.csv that is not in this list stays selectable.

Values: a color is an AutoCAD color number (1–255) or a true color r,g,b, its ... button opens the AutoCAD color dialog; a lineweight is picked from the AutoCAD lineweights; a transparency is 0 (opaque) to 90; scales and factors are numbers greater than 0.

Hatch Settings

SettingUse
PatternThe hatch pattern, picked from every pattern of the .pat files on the support path (acad.pat, acadiso.pat, custom files). A pattern not found stays in the list, marked (not found on the support path). SOLID fills the outline: scales, angle, background colors, lineweight, annotative, drawing scale and the Linear hatch scale and origin are then greyed out and not used.
Scale (imperial)Hatch scale in an imperial drawing (MEASUREMENT = 0).
Scale (metric)Hatch scale in a metric drawing (MEASUREMENT = 1).
AngleHatch angle, in degrees. With the Linear method, the angle of each segment is added so the pattern follows the line.
Layer keyThe layer key of the hatch: the hatch goes on its layer (created with the key properties when missing). A key that is not defined stays in the list, marked (not defined), and draws on a layer of the same name.
ColorOptional. Color of the hatch pattern.
Background colorOptional. Background fill color behind the pattern (not for SOLID).
Existing phase backgroundOptional. Background color used in place of Background color while auto-phase is on and the active phase is E (existing to remain), e.g. to screen the existing work. It needs the DynALisp reactors and PH-AUTO on. Not for SOLID.
LineweightOptional. Lineweight of the pattern (not for SOLID).
Transparency (0-90)Optional. Transparency of the hatch.
Annotative hatchThe hatch is annotative: it shows at the same size at every annotation scale.
Follow the drawing scale (not annotative)The hatch is not annotative but its scale is multiplied by the drawing scale (CANNOSCALE) divided by Scales set for a drawing scale of 1:. Greyed out while Annotative hatch is checked. See Drawing Scale.
Scales set for a drawing scale of 1:The drawing scale the scales above were set for: 10 when they look right at 1:10. Set for 1:10 and drawn at 1:50, the scale is multiplied by 5. The line below gives the factor in the current drawing. The hatch keeps its scale if the drawing scale changes afterwards.
Associative hatchThe hatch follows its border when the border is edited.
Hatch behind its borderThe hatch is sent behind its border (draw order).

Border Settings

The border is the outline drawn or selected around the hatch.

SettingUse
Layer keyThe layer key of the border: the outlines go on its layer. Edit layer keys... opens the Layer Keys window to create or edit keys (saved on its own OK).
ColorOptional. Color of the border.
LinetypeOptional. Linetype of the border, loaded from acad.lin or acadiso.lin when the drawing does not have it (ByLayer and ByBlock are accepted).
Linetype scaleOptional. Linetype scale of the border.
LineweightOptional. Lineweight of the border.
Transparency (0-90)Optional. Transparency of the border.
No borderThe outlines drawn are erased once hatched: only the hatch is left (it is then not associative). The other border settings, Associative hatch and Hatch behind its border are greyed out. Objects picked with Select closed objects are kept.

Material Behaviors

How Quick Draw draws the material. A setting is greyed out unless Draw with is its method or Ask when drawn (the method picked when drawn, or the method of a preset, uses them too).

SettingUse
Draw withThe input method: Ask when drawn (asked on the command line, the default), Polyline, Rectangle, Circle, Polygon, Ellipse, Shrinkwrap (select objects), Pick internal points, Select closed objects or Linear (band along a line). A preset can use another method for itself only. See Draw With.
Width (Linear)Width of the band, in drawing units: 100; several widths divided by commas, 100,150,200, are offered on the command line each time; empty: the last width used (asked the first time).
Line on the (Linear)Where the line drawn is in the band: Ask when drawn, Center (on the line), Left border or Right border (looking from the start point).
Hatch scale = width xOptional (Linear). The hatch scale is the band width times this factor, in place of the scales and drawing scale above: a factor of 0.01 hatches a 100 wide band at 1 and a 200 wide band at 2, so the pattern fits the band.
Hatch origin on the line, offsetOptional (Linear). The pattern of each segment starts on the line at the start of the segment, moved across the line by the offset (0: on the line; positive: into the band), e.g. to line up an insulation pattern with the border.
Sides (Polygon)Number of sides of the Polygon method; empty: asked by POLYGON.
Gap override (Shrinkwrap)Optional (Shrinkwrap). Unchecked: Shrinkwrap starts with a gap of 0 and, when no outline is found, tries larger gaps by the gap step of Dyl-Settings (Drawing Settings). Checked: it starts with the Imperial or Metric gap of the drawing units; an empty gap is asked each time. The larger gaps are tried in every case. See Shrinkwrap – Gap Tolerance.
Imperial / MetricThe gap tolerances of the override, in drawing units: objects closer than the gap are joined into one outline.

New Material

New starts from: pattern ANSI31, scales 1.0 / 1.0, angle 0, border key THIN, hatch key HATCH, annotative and associative, set for 1:1, every optional setting unchecked and Draw with Ask when drawn. Copy starts from the selected material.

Materials File

The materials are saved in Res\Materials.csv (semicolons, one material per row, with a header). Your changes go to its copy under User; the shipped file under Contents gives the default values (status, Reset Selected, Reset All). The columns, in order: Id, Group, Name, Pattern, ScaleImperial, ScaleMetric, Angle, OutlineKey, HatchKey, Annotative, ScaleDrawing, ScaleRef; the optional settings, each one an ...On column (1: checked) and its value: BorderColor, BorderLinetype, BorderLtScale, BorderLineweight (hundredths of mm, 25 = 0.25 mm), BorderTransparency, HatchColor, Background, HatchLineweight, HatchTransparency; then Associative, NoBorder, BehindBorder, Method, Width, Justify, Sides, ScaleWidth, WidthFactor, OriginOnLine, OriginOffset, ExistingBackgroundOn, ExistingBackground, ShrinkGap (imperial), ShrinkGapOn, ShrinkGapMetric. An id starting with mt- is a default material, cu- a custom one. Missing columns get their default value, so a file of an older version still reads.

Each program has one main command starting with Dyl-. The short names are its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv).

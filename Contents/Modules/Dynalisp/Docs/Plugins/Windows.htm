ENFR

Windows

Loaded With DynALisp, by AutoCAD itself (DynALisp.Windows.dll)
Requires AutoCAD 2015 or later for Windows, 64-bit
Licence GNU General Public License v3

Description

The windows of DynALisp are modern windows shown by a plugin that AutoCAD loads with DynALisp: sections in cards, clear text, the same buttons in every window. They are taking the place of the classic AutoCAD dialog boxes one by one, starting with the Settings window and the windows it opens (Drawing Settings, Display, File Preferences, Output Prep). A window works as before: the same settings, the same buttons, the same Open Docs button.

How To Use

  1. Nothing to turn on: the windows open as soon as DynALisp is loaded.
  2. Run a command that has a window, such as Dyl-Settings.
  3. A square open button beside a setting opens its own window over the first one. Its OK keeps what you changed, Cancel puts it back; the first window saves it with the rest.

Notes

  • A setting greyed out cannot be changed now: its checkbox above is off, or its tool is turned off in the Startup Suite.
  • When a window does not open, the command line says why. Run Dyl-Diagnostics: it reports when the plugin is not loaded (an AutoCAD older than 2015, the file blocked by SECURELOAD, or missing).
  • AutoCAD 2010 to 2014 are no longer supported: they cannot load the plugin.
  • For whoever changes DynALisp: the source is Installer\Windows, one project built for .NET 8 and for .NET Framework 4.8, both DLLs committed; each window is a .xaml file of the Res folder of its module.

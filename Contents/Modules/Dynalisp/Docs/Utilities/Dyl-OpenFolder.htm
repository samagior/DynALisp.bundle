Open Folder

Function Syntax DYL-OPENFOLDER
Source File Modules\Dynalisp\Apps\Utilities\Dyl-OpenFolder.lsp
Requires AutoCAD for Windows (Windows Explorer)
Licence GNU General Public License v3

Program Description

Opens a working folder in Windows Explorer: the DynALisp bundle, the current drawing folder, the Dynalisp model templates or the sheet set folder of the current project.

Commands

CommandNameDescription
DYL-OPENFOLDEROpen FolderOpens the repository, current drawing, template or sheet set folder in Windows Explorer.

How It Works

The command prompts Open folder: [Repository/CurrentDrawing/Template/SheetSet] and opens the folder in Windows Explorer:

  • Repository: the DynALisp.bundle folder;
  • CurrentDrawing: the folder of the current drawing;
  • Template: Modules\Dynalisp\Res\Templates\Model;
  • SheetSet: the nearest folder containing a .dst file, searched from the drawing folder up through its parent folders.

A missing folder is reported as Folder not found.

Known Limitations

  • SheetSet opens the folder only; the sheet set itself is not opened in the Sheet Set Manager.
  • For a drawing that has never been saved, CurrentDrawing and SheetSet start from the default drawing folder.

Program Description

This program enables the user modify multiple attributes simultaneously. The program will prompt for selection of an attribute, then a selection of blocks containing attributes of the same tag to modify.

MvAtt allows the user to move selected attributes by a specified displacement; RoAtt allows the user to rotate attributes about their alignment point; finally, EdAtt will allow the user to modify such properties as are checked in the dialog which subsequently appears.

Command Names And Aliases

As in every DynALisp module, each program of this sample module has one main command, named LM-*, and the original command names of Lee Mac's page are kept as its aliases: they run the same command, and can be added, renamed or removed in Dyl-Suite (saved in Resources\Aliases.csv). The rows marked ↳ are child commands of LM-AttributeModificationSuite: they are run by their alias, or picked from LM-AttributeModificationSuite when it lists them (their command is named Pst-*).
